# Bushra

A small listening room for the recordings in this repo.

Open the site (after GitHub Pages is on):

https://lukaweba19-cell.github.io/Bushra/

Tracks currently wired in `index.html`:

- `On the line.mp3`
- `You are the meaning.mp3`

To add another file, drop the `.mp3` in the repo root and add a line to the `tracks` array in `index.html`.
